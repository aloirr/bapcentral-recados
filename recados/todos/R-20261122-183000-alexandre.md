- Nenhum clique do Alexandre. O GitHub Desktop sai do fluxo. Constatado na etapa 0 desta sessão:
  - push pelo shell do PC: bloqueado pelo Cowork (só clone, fetch e download);
  - push pela área de trabalho na nuvem: bloqueado (repositório fora do conjunto autorizado da sessão).
- Por isso, a partir de agora:

  - pastas do PC: o "Fetch/Pull" do Desktop vira git fetch e avanço rápido do main (só fast-forward) pelo shell, quando o Cowork deixar. Nada de commit, checkout de outro branch, rebase ou push pelo shell;
  - as demais regras do R-20261122-182900-alexandre continuam.
