# Deploy automático do Render: a cada publicação no main do GitHub (texto do Alexandre)

## Contexto
Ordem escrita pelo próprio Alexandre na sessão fixa do po, 24/11/2026, por volta das 21:08 (Manaus), quando o po informou que o v0.2.0 aprovado ainda esperava o clique "Manual Deploy" dele no Render. Texto literal:

"Automatize o render . Toda vez que o github publicar ele atualiza"

## O que fica decidido
- O serviço bap-central no Render passa a ter deploy automático a cada commit no main do aloirr/bapcentral (Auto-Deploy "On Commit"). Acaba a exigência da frase "aprovo deploy vX.Y.Z" por versão: o merge no main (com CI verde e pareceres, regras de merge de sempre) já é a liberação do site.
- Muda a ADR 0001 (§4.7 e o "Deploy automático desligado"): adendo novo citando este recado. render.yaml: autoDeploy: true (governança; PR com "Agente: alexandre", merge com o "autorizo" pelo po por delegação de R-20261120-110406).
- [LEITURA DO PO] O serviço foi criado pelo navegador; a chave que vale de fato é a do painel do Render (Settings → Build & Deploy → Auto-Deploy). O Alexandre liga no painel; o time alinha o render.yaml e a ADR.
- Continua: o robô novo só é instalado no PC depois de o site com a versão nova estar no ar (/saude) — "instale" segue valendo por instalação; segredos só pelo Alexandre.
